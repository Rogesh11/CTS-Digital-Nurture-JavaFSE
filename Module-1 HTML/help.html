Smart Community Event Portal - Help Center

Welcome to the Smart Community Event Portal Help Center. This page opens in a new tab when you click the HELP link.

How to Register for an Event

  1. Open the Register section from the navigation menu.
  2. Enter your Name, Email, Phone Number and Event Date.
  3. Select your preferred event.
  4. Provide your message and feedback.
  5. Click Register Event.
  6. A registration confirmation message will be displayed.

Saving Preferences

Your selected event is automatically saved using Local Storage so it can be remembered when you revisit the portal.

Finding Nearby Events

Click Find Nearby Events and allow location access. The portal will display your current coordinates.

Event Gallery

Browse community event images. Double-click an image to enlarge it.

Promo Video

Play the community promotional video in the Gallery section. A status message appears when the video is ready.

Clear Preferences

Use the Clear Preferences button to remove saved data from Local Storage and Session Storage.
